# Moneyball 7.2 — current production and trust boundaries

Verified 2026-11-04 UTC.

## Production outputs (public NFL data only)
- `data/_MONEYBALL_FEED_2026.json.gz`: NFL box/PBP/snaps partial, generated by Moneyball 5.
- `data/_MONEYBALL7_SCOUT_2026.json.gz`: observed disjoint 2 vs 2 utilization and null routes.
- `data/_MONEYBALL7_CONTEXT_2026.json.gz`: 32 DST, 33 kickers; NFL observed PBP/weekly statistics, not projected fantasy points.
- `data/_MONEYBALL72_PROJECTION_2026.json.gz`: rolling last-4 game PPR historical reference (minimum 3 observations), injury provenance and walk-forward error audit. **Despite the filename, NOT a calibrated future projection.** 

The PPR backtest tests one-step-ahead outcomes in completed 2026 weeks 4-8.
Only cases where the prior conditional PPR average was at least 5 and
the next game had PPR observed are scored. This removes zero-point fringe
players dominating the error measure; **selection and participation bias remain**.
As of 2026-11-04, 795 examples; MAE ~6.26 PPR; this is not a true-week
start/sit or championship probability calibration.

## Private league integration

Sleeper league rosters, confirmed Trade Block messages, waivers and draft/trade
evaluations are handled in the user's *private* Google Apps Script, not
uploaded to this public repository. The v7.2 Apps Script extension produces:

- `MB72_TRADES`: roster 1-for-1 scenarios from verified current ownership
  using the seven **offensive** starting positions (QB, RB, RB, WR, WR, TE,
  FLEX=RB/WR). It does not calculate K/DST because this trade leaves them
  unchanged.
- `MB72_HORIZONTES`: changes to best legal **offensive** lineup for the
  current week, next 3-5 and postseason weeks 15-17; uses NFL 2026
  official/sourced schedule to remove BYE players.
- `MB72_SALUD`: source-date qualification, Sleeper injury tags; if provider
  has no trustworthy modified timestamp, it is never a verified current
  practice report.
- `MB72_REEMPLAZO`: possible free-agent historical alternatives. Public
  roster absence is not waiver eligibility.
- `MB72_CALIDAD`: data quality, coverage and visible error.

The trade illustration has **zero automatic execution**; no waiver claim,
lineup, FAAB, trade or private message is accessed or changed.

## Unfinished gates (MUST NOT claim fully integrated Moneyball)

1. Official current-week NFL practice reports with reliable publication
   timestamps and legal automated access. The 2026 nflverse injuries file
   gave **zero reliable event timestamps in 2011 records** at the cutoff.
   A stale historical report is *not* medical clearance.
2. Route participation, TPRR, tracking and every player-week first read
   require authorized providers. They remain NULL rather than being
   reconstructed from targets.
3. Matchup-aware injury-adjusted PPR forecasting and walk-forward
   calibration on future data, rather than four-game history.
4. Six-team playoff bracket reconstruction, verified tie-break rules,
   and Monte Carlo with uncertainty and sensitivity analysis BEFORE
   assigning numeric odds of winning the title.
5. Apps Script production confirmation requires the user to replace
   Code.gs and run `probarMoneyball72`, `probarFuenteRealMoneyball72`,
   `actualizarMoneyball` and `verificarMoneyball72`.
   This repo alone cannot modify an Apps Script project.

## Safeguards

- Do not publish identifiable manager or league roster snapshots here.
- Never treat `N/D` as numeric zero.
- No stale feed gets counted as a current trade evaluation.
- No simulated win odds without verified scoring, lineup, injuries, timing,
  schedule, playoff rules and backtesting.
- Keep prior Moneyball 5/6/7.0/7.1 data and `DECISIONES` intact.
- Sources: nflverse data repository, Sleeper public read-only API and
  DynastyProcess crosswalk; preserve source attribution and licenses.
